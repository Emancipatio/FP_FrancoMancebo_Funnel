Set it up once

Three steps, about two minutes

  1. In Claude, open Settings → Capabilities and turn on Code execution and file creation.
  2. Open Customize → Skills, choose Upload a skill and pick the right-hand-kit.zip you just downloaded.
  3. Connect Gmail and Google Calendar in Settings → Connectors, start a new chat and type audit my week.

Using Claude Code? Unzip it into ~/.claude/skills/. Skills and Google connectors are available on every Claude plan, Free included.
